## About The Project

This project I want to make Aztup Hub V3 source fully working. With all the games and even host my scripts using its UI.

Here's why:
* I really like the framework of it
* It's a fun little goal to work up to
* Outside of it being a script it serves good as a UI lib

This project is completely open source with the fixes except for the "payloads" which are scripts I made for other games.
If any scripters reading this and want to use the UI lib feel free to DM me on Discord `t3nv0`, I'm willing to take suggestions and
make adjustments as needed

To use the Script scroll down <br>
To learn how to make "payloads" check `payloads/Example`<br>

